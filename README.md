# Unofficial EGA in Simplified Chinese / 非官方 EGA 简体中文版

This repository is the single cumulative publication lineage for the independent, unofficial mainland Simplified-Chinese (`zh-Hans-CN`) edition of *Éléments de géométrie algébrique* by Alexander Grothendieck and Jean Dieudonné.

The initial preserved release contains the complete EGA II fascicle: front matter, §§1–8 through §8.14.14, bibliography, indexes, contents, and *Errata et Addenda, Liste 1*, through printed page 222. EGA I is not part of this release and may be added later as a successor in this same repository and Zenodo concept lineage.

## Current release

- Reader: [`ega2-zh-hans-cn.pdf`](releases/2026-08-26-ega-ii/ega2-zh-hans-cn.pdf)
- Editable-source archive: [`ega2-zh-hans-cn-source.zip`](releases/2026-08-26-ega-ii/ega2-zh-hans-cn-source.zip)
- Exact inventory and QA evidence: [`releases/2026-08-26-ega-ii/`](releases/2026-08-26-ega-ii/)

The reader has passed deterministic corpus/formula/reference replay, serial LuaLaTeX builds, font and glyph checks, text extraction, link validation, privacy review, archive replay, and all-page visual inspection. Its status is producer-complete and mechanically/visually verified, but not independently certified for Chinese prose.

## Provenance and relationship

This language edition is a child of the cumulative EGA source programme represented by [Zenodo concept DOI 10.5281/zenodo.20414353](https://doi.org/10.5281/zenodo.20414353). It does not replace the French, English, Korean, or global source lineages.

The NUMDAM authority scan, canonical French transcription, and English comparison witnesses are excluded from the release packet. Their identities are recorded in the release manifest solely for provenance and deterministic source locking.
